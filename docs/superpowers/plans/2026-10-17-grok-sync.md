# Grok Bot Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A "Sync with Grok Bot" button on the org tab row that previews and applies the merge between the org folder and a snapshot file the Connector writes, plus a "Reports to" select so the org chart can be reshaped from the app.

**Architecture:** The org folder is the channel. The Connector overwrites `orgs/<slug>/grok/snapshot.json`; the writer watches `grok/`, plans a merge with a pure module, and applies it through the existing seat and process writers. The app owns structure, Grok Bot owns facts, nothing is ever deleted. Frontend shows a preview drawer and tags on the chart.

**Tech Stack:** Node 22, TypeScript, Vite, React 19, `node --test` with tsx. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-17-grok-sync-design.md`

## Global Constraints

- User-facing text says organization, never company. Paths and `orgs/` stay as they are.
- Every button is `src/components/Button.tsx`. Native `<select>` for selects. No `style` prop. No hex outside `src/styles/tokens.css`. Square corners.
- Every org-file reader tolerates a BOM, CRLF, and a bad file. A bad file is skipped and never crashes the writer, the watcher, or the page.
- Writes are UTF-8 without a BOM and LF, which is what `writeFileSync` with a string and the existing serializers already produce.
- The sync never deletes a seat, retires a seat, changes an existing seat's manager, overwrites a filled card section, edits an existing process, or writes `grok/snapshot.json`.
- `npm test` and `npm run build` before each commit. `npm test` has one known environment failure on this machine (`org-node-layout.test.ts` needs Chrome at a Linux path). After a build, `git checkout -- src/generated/bots.ts` unless the task is about that file.
- Small commits on the `feat/grok-sync` branch. Never push to `main`.

## Review Focus

1. A snapshot bot whose name matches a **retired** seat must update facts on the retired seat, not create a second seat and not reactivate it. Test in Task 4.
2. A snapshot that lists a bot **twice** under the same name must match the seat once and create one `-2` seat for the duplicate rather than crashing or writing twice. Test in Task 4.
3. A seat file written by **Grok Bot** itself with a BOM and CRLF must patch cleanly and come back without a BOM and with LF. Test in Task 4.
4. Moving a seat under one of its **own reports** must be refused with a message, and `org.md` must stay consistent after any accepted move. Test in Task 6.
5. The Sync button must **not** render on a template, a sample, or in showcase mode, where the writer is absent. Test in Task 8.

```ts
/** Finds the seat a bot reports to: You, an existing seat by title or slug, or another bot in the same file. */
export function resolveManager(
  reportsTo: string,
  ownName: string,
  existing: { slug: string; title: string }[],
  batch: Map<string, string>,
): { ok: true; slug: string; isNew: boolean } | { ok: false; error: string } {
  const name = reportsTo.trim() || 'You'
  if (name.toLowerCase() === ownName.trim().toLowerCase()) return { ok: false, error: `${ownName} cannot report to itself.` }
  if (name.toLowerCase() === 'you') {
    const titled = existing.find((seat) => seat.title.trim().toLowerCase() === 'you')
    const founder = titled ?? existing.find((seat) => seat.slug === 'you')
    if (!founder) return { ok: false, error: 'You is not a seat in this org.' }
    return { ok: true, slug: founder.slug, isNew: false }
  }
  const titled = existing.find((seat) => seat.title.trim().toLowerCase() === name.toLowerCase())
  if (titled) return { ok: true, slug: titled.slug, isNew: false }
  const batched = batch.get(name.toLowerCase())
  if (batched) return { ok: true, slug: batched, isNew: true }
  if (SEAT_SLUG.test(name) && existing.some((seat) => seat.slug === name)) {
    return { ok: true, slug: name, isNew: false }
  }
  return { ok: false, error: `${name} is not a seat in this org or in this file.` }
}
```

```ts
import { parseBotsFile, resolveManager, type BotsFileRow } from './bots-file.ts'
import { formatShortDate } from './bot-metrics.ts'
import { normalizeText } from './normalize-text.ts'
import { parseSeatMarkdown, serializeSeat, type BotRoutine, type BotRunStatus, type GrokSyncState, type SeatDocument } from './org-files.ts'
import { parseProcessesFile, processSlug, type ProcessFile, type ProcessImportRow } from './processes.ts'

export interface Snapshot {
  syncedAt: string
  bots: BotsFileRow[]
  processes: ProcessImportRow[]
}

export interface SeatPatch {
  title?: string
  role?: string
  grokBotUrl?: string
  createdAt?: string
  lastActive?: string
  runs30d?: number
  tasksDone30d?: number
  routines?: BotRoutine[]
  botStatus?: BotRunStatus
  owns?: string[]
  may?: string[]
  mustAskBefore?: string[]
  doneWhen?: string[]
  grokSync: GrokSyncState
  grokSyncedAt?: string
  /** null clears the field. */
  grokMissingSince?: string | null
}

export type SyncRow =
  | { kind: 'new'; name: string; bot: BotsFileRow; note: string }
  | { kind: 'updated'; name: string; slug: string; renamed: boolean; changes: string[]; patch: SeatPatch }
  | { kind: 'unchanged'; name: string; slug: string }
  | { kind: 'missing'; name: string; slug: string; write: boolean; patch: SeatPatch }
  | { kind: 'new-process'; name: string; row: ProcessImportRow }
  | { kind: 'schedule'; name: string; slug: string; process: string; routine: string }
  | { kind: 'skipped'; name: string; error: string }

export interface SyncCounts {
  new: number
  missing: number
  updated: number
  processes: number
  warnings: number
  unchanged: number
}

export interface SyncPlan {
  syncedAt: string
  rows: SyncRow[]
  counts: SyncCounts
  /** Rows that write a file when confirmed. */
  writes: number
}

/** What GET /api/orgs/<slug>/sync returns. */
export interface SyncStatus {
  snapshot: { stamp: string; syncedAt: string } | null
  error: string
  plan: SyncPlan | null
  lastConfirmed: string
}

export function parseSnapshot(text: string, fallbackSyncedAt: string): { ok: true; snapshot: Snapshot } | { ok: false; error: string } {
  const clean = normalizeText(text)
  let parsed: unknown
  try {
    parsed = JSON.parse(clean)
  } catch {
    return { ok: false, error: 'This file is not JSON.' }
  }
  if (!parsed || typeof parsed !== 'object' || Array.isArray(parsed)) {
    return { ok: false, error: 'The snapshot must be a JSON object with a bots list.' }
  }
  const record = parsed as { syncedAt?: unknown; bots?: unknown; processes?: unknown }
  if (!Array.isArray(record.bots)) return { ok: false, error: 'The snapshot needs a bots list.' }
  let bots: BotsFileRow[] = []
  if (record.bots.length) {
    const read = parseBotsFile(clean)
    if (!read.ok) return { ok: false, error: read.errors.join(' ') }
    bots = read.rows
  }
  let processes: ProcessImportRow[] = []
  if (record.processes !== undefined && record.processes !== null) {
    const read = parseProcessesFile(clean)
    if (!read.ok) return { ok: false, error: read.errors.join(' ') }
    processes = read.rows
  }
  const stamp = typeof record.syncedAt === 'string' && !Number.isNaN(Date.parse(record.syncedAt))
    ? new Date(record.syncedAt).toISOString()
    : fallbackSyncedAt
  return { ok: true, snapshot: { syncedAt: stamp, bots, processes } }
}

export function planSync(snapshot: Snapshot, seats: SeatDocument[], processes: ProcessFile[]): SyncPlan {
  const rows: SyncRow[] = []
  const claimed = new Set<string>()
  const matched: { bot: BotsFileRow; seat: SeatDocument; byUrl: boolean }[] = []
  const fresh: BotsFileRow[] = []
  for (const bot of snapshot.bots) {
    if (bot.error) {
      rows.push({ kind: 'skipped', name: bot.name, error: bot.error })
      continue
    }
    const found = findSeat(bot, seats, claimed)
    if (!found) {
      fresh.push(bot)
      continue
    }
    claimed.add(found.seat.slug)
    matched.push({ bot, seat: found.seat, byUrl: found.byUrl })
  }

  const existing = seats.map((item) => ({ slug: item.slug, title: item.title }))
  const batch = new Map<string, string>()
  for (const bot of fresh) batch.set(bot.name.trim().toLowerCase(), slugify(bot.name))
  for (const bot of fresh) {
    const resolved = resolveManager(bot.reportsTo, bot.name, existing, batch)
    if (resolved.ok) {
      rows.push({ kind: 'new', name: bot.name, bot, note: bot.note })
      continue
    }
    const note = `${bot.reportsTo.trim() || 'You'} is not a seat here, placed under You.`
    rows.push({ kind: 'new', name: bot.name, bot: { ...bot, reportsTo: 'You' }, note: bot.note ? `${bot.note} ${note}` : note })
  }

  for (const { bot, seat, byUrl } of matched) {
    const row = diffSeat(bot, seat, byUrl, snapshot.syncedAt)
    rows.push(row)
  }

  for (const seat of seats) {
    if (seat.kind !== 'bot' || seat.status === 'retired' || claimed.has(seat.slug)) continue
    const already = seat.grokSync === 'missing'
    rows.push({
      kind: 'missing',
      name: seat.title,
      slug: seat.slug,
      write: !already,
      patch: { grokSync: 'missing', grokMissingSince: already ? seat.grokMissingSince ?? snapshot.syncedAt : snapshot.syncedAt },
    })
  }

  const bySlug = new Map(processes.map((process) => [process.slug, process]))
  const seen = new Set<string>()
  for (const row of snapshot.processes) {
    if (row.error) {
      rows.push({ kind: 'skipped', name: row.name || 'Process', error: row.error })
      continue
    }
    const slug = processSlug(row.name)
    if (!slug || seen.has(slug)) continue
    seen.add(slug)
    const current = bySlug.get(slug) ?? processes.find((process) => process.name.trim().toLowerCase() === row.name.trim().toLowerCase())
    if (!current) {
      rows.push({ kind: 'new-process', name: row.name, row })
      continue
    }
    const routine = row.trigger.schedule.trim()
    const process = current.trigger.schedule.trim()
    if (row.trigger.type === 'schedule' && current.trigger.type === 'schedule' && routine && routine !== process) {
      rows.push({ kind: 'schedule', name: row.name, slug: current.slug, process, routine })
    }
  }

  const counts: SyncCounts = {
    new: rows.filter((row) => row.kind === 'new').length,
    missing: rows.filter((row) => row.kind === 'missing' && row.write).length,
    updated: rows.filter((row) => row.kind === 'updated').length,
    processes: rows.filter((row) => row.kind === 'new-process').length,
    warnings: rows.filter((row) => row.kind === 'schedule').length,
    unchanged: rows.filter((row) => row.kind === 'unchanged').length,
  }
  return { syncedAt: snapshot.syncedAt, rows, counts, writes: counts.new + counts.missing + counts.updated + counts.processes }
}

export function summaryLine(counts: SyncCounts): string {
  const parts: string[] = []
  if (counts.new) parts.push(`${counts.new} new`)
  if (counts.missing) parts.push(`${counts.missing} missing`)
  if (counts.updated) parts.push(`${counts.updated} updated`)
  if (counts.processes) parts.push(`${counts.processes} new ${counts.processes === 1 ? 'process' : 'processes'}`)
  return parts.length ? parts.join(', ') : 'Nothing to sync'
}

export function patchSeatSource(slug: string, source: string, patch: SeatPatch): { ok: true; source: string } | { ok: false; errors: string[] } {
  const parsed = parseSeatMarkdown(slug, source)
  if (!parsed.ok) return parsed
  const next: SeatDocument = { ...parsed.seat, grokSync: patch.grokSync, source: '' }
  if (patch.title !== undefined) {
    next.title = patch.title
    next.role = patch.role ?? patch.title
  }
  if (patch.grokBotUrl !== undefined) next.grokBotUrl = patch.grokBotUrl
  if (patch.createdAt !== undefined) next.createdAt = patch.createdAt
  if (patch.lastActive !== undefined) next.lastActive = patch.lastActive
  if (patch.runs30d !== undefined) next.runs30d = patch.runs30d
  if (patch.tasksDone30d !== undefined) next.tasksDone30d = patch.tasksDone30d
  if (patch.routines !== undefined) next.routines = patch.routines
  if (patch.botStatus !== undefined) next.botStatus = patch.botStatus
  if (patch.owns !== undefined) next.owns = patch.owns
  if (patch.may !== undefined) next.may = patch.may
  if (patch.mustAskBefore !== undefined) next.mustAskBefore = patch.mustAskBefore
  if (patch.doneWhen !== undefined) next.doneWhen = patch.doneWhen
  if (patch.grokSyncedAt !== undefined) next.grokSyncedAt = patch.grokSyncedAt
  if (patch.grokMissingSince === null) delete next.grokMissingSince
  else if (patch.grokMissingSince !== undefined) next.grokMissingSince = patch.grokMissingSince
  const written = serializeSeat(next)
  const check = parseSeatMarkdown(slug, written)
  if (!check.ok) return check
  return { ok: true, source: written }
}

function findSeat(bot: BotsFileRow, seats: SeatDocument[], claimed: Set<string>): { seat: SeatDocument; byUrl: boolean } | null {
  const link = bot.grokBotUrl.trim()
  if (link) {
    const byUrl = seats.find((seat) => !claimed.has(seat.slug) && (seat.grokBotUrl ?? '').trim() === link)
    if (byUrl) return { seat: byUrl, byUrl: true }
  }
  const name = bot.name.trim().toLowerCase()
  const byName = seats.find((seat) => !claimed.has(seat.slug) && seat.title.trim().toLowerCase() === name)
  if (byName) return { seat: byName, byUrl: false }
  const slug = slugify(bot.name)
  const bySlug = seats.find((seat) => !claimed.has(seat.slug) && seat.slug === slug)
  return bySlug ? { seat: bySlug, byUrl: false } : null
}

function diffSeat(bot: BotsFileRow, seat: SeatDocument, byUrl: boolean, syncedAt: string): SyncRow {
  const changes: string[] = []
  const patch: SeatPatch = { grokSync: 'synced' }
  const name = bot.name.trim()
  if (byUrl && name !== seat.title.trim()) {
    patch.title = name
    patch.role = seat.role.trim() === seat.title.trim() ? name : seat.role
    changes.push(`name → ${name}`)
  }
  if (bot.grokBotUrl && bot.grokBotUrl !== (seat.grokBotUrl ?? '')) {
    patch.grokBotUrl = bot.grokBotUrl
    changes.push('link')
  }
  if (bot.createdAt && bot.createdAt !== (seat.createdAt ?? '')) {
    patch.createdAt = bot.createdAt
    changes.push(`created ${formatShortDate(bot.createdAt)}`)
  }
  if (bot.lastActive && bot.lastActive !== (seat.lastActive ?? '')) {
    patch.lastActive = bot.lastActive
    changes.push(`last active ${formatShortDate(bot.lastActive)}`)
  }
  if (bot.runs30d !== undefined && bot.runs30d !== seat.runs30d) {
    patch.runs30d = bot.runs30d
    changes.push(`${bot.runs30d} runs`)
  }
  if (bot.tasksDone30d !== undefined && bot.tasksDone30d !== seat.tasksDone30d) {
    patch.tasksDone30d = bot.tasksDone30d
    changes.push(`${bot.tasksDone30d} tasks`)
  }
  if (bot.routines.length && JSON.stringify(bot.routines) !== JSON.stringify(seat.routines ?? [])) {
    patch.routines = bot.routines
    changes.push(`${bot.routines.length} ${bot.routines.length === 1 ? 'routine' : 'routines'}`)
  }
  if (bot.botStatus && bot.botStatus !== seat.botStatus) {
    patch.botStatus = bot.botStatus
    changes.push(bot.botStatus)
  }
  const fills: [keyof Pick<SeatPatch, 'owns' | 'may' | 'mustAskBefore' | 'doneWhen'>, string, string[]][] = [
    ['owns', 'Owns', bot.owns],
    ['may', 'May', bot.may],
    ['mustAskBefore', 'Needs approval', bot.needsApproval],
    ['doneWhen', 'Done when', bot.doneWhen],
  ]
  for (const [key, label, lines] of fills) {
    if (seat[key].some((line) => line.trim()) || !lines.length) continue
    patch[key] = lines
    changes.push(`${label} filled`)
  }
  if (seat.grokSync === 'missing') {
    patch.grokMissingSince = null
    changes.push('found again')
  }
  if (seat.grokSync === 'new') changes.push('no longer new')
  if (!changes.length) return { kind: 'unchanged', name: seat.title, slug: seat.slug }
  patch.grokSyncedAt = syncedAt
  return { kind: 'updated', name: seat.title, slug: seat.slug, renamed: patch.title !== undefined, changes, patch }
}

function slugify(name: string): string {
  return name.toLowerCase().replace(/[^a-z0-9]+/g, '-').replace(/^-+|-+$/g, '').slice(0, 48)
}
```

```ts
export function readSnapshot(root: string): { ok: true; snapshot: Snapshot; stamp: string } | { ok: false; error: string; stamp: string; missing: boolean } {
  const path = resolve(root, SNAPSHOT_PATH)
  if (!existsSync(path)) return { ok: false, error: '', stamp: '', missing: true }
  let stamp = ''
  let fallback = new Date().toISOString()
  try {
    const stat = statSync(path)
    stamp = `${Math.round(stat.mtimeMs)}:${stat.size}`
    fallback = stat.mtime.toISOString()
  } catch {
    return { ok: false, error: 'Could not read the snapshot.', stamp: '', missing: false }
  }
  let text: string
  try {
    text = readText(path)
  } catch {
    return { ok: false, error: 'Could not read the snapshot.', stamp, missing: false }
  }
  const parsed = parseSnapshot(text, fallback)
  if (!parsed.ok) return { ok: false, error: parsed.error, stamp, missing: false }
  return { ok: true, snapshot: parsed.snapshot, stamp }
}

function lastSyncConfirmed(bundle: OrgBundle): string {
  let latest = ''
  for (const event of bundle.activity) {
    if (event.id.startsWith('sync-') && event.timestamp > latest) latest = event.timestamp
  }
  return latest
}

export function syncStatus(root: string, orgId: string): { ok: true; status: SyncStatus } | { ok: false; errors: string[] } {
  const read = readOrgDir(root, orgId)
  if (!read.ok) return read
  const lastConfirmed = lastSyncConfirmed(read.bundle)
  const snap = readSnapshot(root)
  if (!snap.ok) {
    if (snap.missing) return { ok: true, status: { snapshot: null, error: '', plan: null, lastConfirmed } }
    return { ok: true, status: { snapshot: { stamp: snap.stamp, syncedAt: '' }, error: snap.error, plan: null, lastConfirmed } }
  }
  const plan = planSync(snap.snapshot, read.bundle.seats, read.bundle.processes ?? [])
  return { ok: true, status: { snapshot: { stamp: snap.stamp, syncedAt: snap.snapshot.syncedAt }, error: '', plan, lastConfirmed } }
}

export function previewSnapshotJson(root: string, orgId: string, json: string): { ok: true; status: SyncStatus } | { ok: false; errors: string[] } {
  const read = readOrgDir(root, orgId)
  if (!read.ok) return read
  const parsed = parseSnapshot(json, new Date().toISOString())
  if (!parsed.ok) return { ok: false, errors: [parsed.error] }
  const plan = planSync(parsed.snapshot, read.bundle.seats, read.bundle.processes ?? [])
  return { ok: true, status: { snapshot: { stamp: '', syncedAt: parsed.snapshot.syncedAt }, error: '', plan, lastConfirmed: lastSyncConfirmed(read.bundle) } }
}

export function applySync(
  root: string,
  orgId: string,
  plan: SyncPlan,
): { ok: true; counts: SyncCounts; summary: string; errors: { name: string; error: string }[]; notes: string[]; files: string[] } | { ok: false; errors: string[] } {
  if (!orgExists(root)) return { ok: false, errors: ['Org not found.'] }
  const read = readOrgDir(root, orgId)
  if (!read.ok) return read
  const errors: { name: string; error: string }[] = []
  const notes: string[] = []
  const files: string[] = []
  const counts: SyncCounts = { new: 0, missing: 0, updated: 0, processes: 0, warnings: plan.counts.warnings, unchanged: plan.counts.unchanged }

  const fresh = plan.rows.flatMap((row) => (row.kind === 'new' ? [row.bot] : []))
  if (fresh.length) {
    const imported = importBotsFile(root, orgId, fresh, { grokSync: 'new', grokSyncedAt: plan.syncedAt })
    counts.new = imported.imported.length
    files.push(...imported.imported.map((item) => item.file))
    errors.push(...imported.errors)
  }

  for (const row of plan.rows) {
    if (row.kind !== 'updated' && !(row.kind === 'missing' && row.write)) continue
    const path = seatFile(root, row.slug)
    if (!path || !existsSync(path)) {
      errors.push({ name: row.name, error: `seats/${row.slug}.md is not in this org.` })
      continue
    }
    let source: string
    try {
      source = readText(path)
    } catch {
      errors.push({ name: row.name, error: `seats/${row.slug}.md could not be read.` })
      continue
    }
    const patched = patchSeatSource(row.slug, source, row.patch)
    if (!patched.ok) {
      errors.push({ name: row.name, error: patched.errors.join(' ') })
      continue
    }
    writeFileSync(path, patched.source)
    files.push(`orgs/${orgId}/seats/${row.slug}.md`)
    if (row.kind === 'updated') counts.updated += 1
    else counts.missing += 1
  }

  const processRows = plan.rows.flatMap((row) => (row.kind === 'new-process' ? [row.row] : []))
  if (processRows.length) {
    const imported = importProcessRows(root, processRows, read.bundle.seats.map((seat) => ({ slug: seat.slug, title: seat.title })))
    counts.processes = imported.imported.length
    files.push(...imported.imported.map((item) => `orgs/${orgId}/${item.file}`))
    errors.push(...imported.errors)
    notes.push(...imported.notes)
  }

  const summary = summaryLine(counts)
  if (files.length) {
    const connector = read.bundle.seats.find((seat) => seat.title.trim().toLowerCase() === 'connector - botseverywhere')
    const stamp = new Date().toISOString()
    appendActivity(root, {
      id: `sync-${stamp}`,
      orgId,
      type: 'edit',
      actorSeatId: connector?.slug || 'grok-bot',
      actorType: 'bot',
      timestamp: stamp,
      summary: `Synced with Grok Bot: ${summary}`,
    })
  }
  return { ok: true, counts, summary, errors, notes, files }
}
```

```ts
export function setSeatManager(root: string, orgId: string, slug: string, reportsTo: string): { ok: true; file: string } | { ok: false; errors: string[] } {
  if (unsafePath(slug) || unsafePath(reportsTo)) return { ok: false, errors: ['That name is not a safe file name.'] }
  if (!SEAT_SLUG.test(slug)) return { ok: false, errors: ['Seat slug must be a lowercase slug.'] }
  const target = reportsTo.trim()
  if (!SEAT_SLUG.test(target)) return { ok: false, errors: ['reportsTo must be a seat slug.'] }
  const read = readOrgDir(root, orgId)
  if (!read.ok) return read
  const seat = read.bundle.seats.find((item) => item.slug === slug)
  if (!seat) return { ok: false, errors: [`seats/${slug}.md is not in this org.`] }
  const manager = read.bundle.seats.find((item) => item.slug === target)
  if (!manager) return { ok: false, errors: [`${target} is not a seat in this org.`] }
  if (target === slug) return { ok: false, errors: [`${seat.title} cannot report to itself.`] }
  const parent = new Map(read.bundle.org.seats.map((item) => [item.slug, item.reportsTo || '']))
  const seen = new Set<string>()
  let cursor = target
  while (cursor) {
    if (cursor === slug) return { ok: false, errors: [`${manager.title} reports to ${seat.title}. Pick another manager.`] }
    if (seen.has(cursor)) break
    seen.add(cursor)
```

```ts
import type { SyncRow, SyncStatus } from '../../server/src/grok-sync.ts'

export function syncButtonLabel(writes: number): string {
  return writes > 0 ? `Sync with Grok Bot · ${writes}` : 'Sync with Grok Bot'
}

export function rowLine(row: SyncRow): string {
  switch (row.kind) {
    case 'new':
      return `${row.name} → new seat, reports to ${row.bot.reportsTo}${row.note ? `. ${row.note}` : ''}`
    case 'updated':
      return `${row.name} → ${row.changes.join(', ')}`
    case 'missing':
      return row.write ? `${row.name} → not found in Grok Bot` : `${row.name} → still not found`
    case 'new-process':
      return `${row.name} → new process`
    case 'schedule':
      return `${row.name} → Grok Bot runs it "${row.routine}", the process says "${row.process}"`
    case 'skipped':
      return `${row.name} → ${row.error}`
    case 'unchanged':
      return `${row.name} → unchanged`
  }
}

export function statusLine(status: Pick<SyncStatus, 'snapshot' | 'error' | 'lastConfirmed'>, slug: string): string {
  if (status.error) return `The snapshot could not be read: ${status.error}`
  if (!status.snapshot) return `No snapshot yet. The Connector writes orgs/${slug}/grok/snapshot.json on each run.`
  const confirmed = status.lastConfirmed ? ` Last confirmed ${formatShortDate(status.lastConfirmed)}.` : ' Not confirmed yet.'
  return `Snapshot from ${formatShortDate(status.snapshot.syncedAt)}.${confirmed}`
}

export function grokSyncTag(seat: { grokSync?: 'new' | 'synced' | 'missing' }): string {
  if (seat.grokSync === 'new') return 'New'
  if (seat.grokSync === 'missing') return 'Not found in Grok Bot'
  return ''
}

export function grokSyncLine(seat: { grokSync?: 'new' | 'synced' | 'missing'; grokSyncedAt?: string; grokMissingSince?: string }): string {

  if (seat.grokSync === 'new') return `new since ${formatShortDate(seat.grokSyncedAt ?? '')}`
  if (seat.grokSync === 'missing') return `not found since ${formatShortDate(seat.grokMissingSince ?? '')}`
  return 'not synced yet'
```

```ts
/** Seats a given seat may report to: active, not itself, and not one of its own reports. */
export function managerChoices(
  seats: { slug: string; title: string; reportsTo: string; status: string }[],
  slug: string,
): { slug: string; title: string }[] {
  const below = new Set<string>([slug])
  let grew = true
  while (grew) {
    grew = false
    for (const seat of seats) {
      if (!below.has(seat.slug) && seat.reportsTo && below.has(seat.reportsTo)) {
        below.add(seat.slug)
        grew = true
      }
    }
  }
  return seats
    .filter((seat) => seat.status !== 'retired' && !below.has(seat.slug))
    .map((seat) => ({ slug: seat.slug, title: seat.title }))
}
```

```tsx
import { useRef, useState } from 'react'
import type { SyncPlan, SyncRow, SyncStatus } from '../../server/src/grok-sync.ts'
import { GROK_SNAPSHOT_PROMPT, SYNC_NOW_PROMPT } from '../content/grok-snapshot-prompt'

import { Button } from './Button'
import { SaveAlert } from './SaveAlert'
import { saveNotice, type SaveNotice } from './save-notice'
import { rowLine, statusLine } from './sync-copy'

const SAVING_OFF = 'Saving is off. Restart npm run dev, then sync again.'
const STALE = 'The snapshot changed. Review it again.'

type Source = { kind: 'file' } | { kind: 'json'; json: string; status: SyncStatus }

export function SyncDrawer({
  orgSlug,
  status,
  onClose,
  onRefresh,
  onApplied,
}: {
  orgSlug: string
  status: SyncStatus | null
  onClose: () => void
  onRefresh: () => Promise<void>
  onApplied: (message: string) => Promise<void>
}) {
  const [source, setSource] = useState<Source>({ kind: 'file' })
  const [busy, setBusy] = useState(false)
  const [notice, setNotice] = useState<SaveNotice | null>(null)
  const fileRef = useRef<HTMLInputElement>(null)
  const shown = source.kind === 'json' ? source.status : status
  const plan = shown?.plan ?? null

  async function confirm() {
    if (!plan || plan.writes === 0 || busy) return
    setBusy(true)
    setNotice(null)
    try {
      const body = source.kind === 'json'
        ? { source: 'json', json: source.json }
        : { source: 'file', stamp: shown?.snapshot?.stamp ?? '' }
      const response = await fetch(`/api/orgs/${orgSlug}/sync/apply`, {
        method: 'POST',
        headers: { 'content-type': 'application/json' },
        body: JSON.stringify(body),
      })
      const text = await response.text()
      const result = text.trimStart().startsWith('{') ? JSON.parse(text) as { summary?: string; errors?: unknown; error?: string } : {}
      if (response.status === 409) {
        await onRefresh()
        setNotice(saveNotice(false, STALE))
        return
      }
      if (!response.ok) {
        const reasons = Array.isArray(result.errors) ? result.errors.map(String).join(' ') : result.error || 'Could not sync.'
        setNotice(saveNotice(false, reasons, 'Not synced'))
        return
      }
      const skipped = Array.isArray(result.errors)
        ? result.errors.flatMap((item) => {
          if (!item || typeof item !== 'object') return []
          const row = item as { name?: string; error?: string }
          return [`Skipped ${row.name || 'a row'}: ${row.error || 'could not sync it.'}`]
        }).join(' ')
        : ''
      await onApplied(skipped ? `Synced: ${result.summary ?? ''}. ${skipped}` : `Synced: ${result.summary ?? ''}`)
    } catch {
      setNotice(saveNotice(false, SAVING_OFF, 'Not synced'))
    } finally {
      setBusy(false)
    }
  }

  async function preview(file: File) {
    setNotice(null)
    const json = await file.text()
    try {
      const response = await fetch(`/api/orgs/${orgSlug}/sync/preview`, { method: 'POST', body: json })
      const text = await response.text()
      const result = text.trimStart().startsWith('{') ? JSON.parse(text) as SyncStatus & { errors?: string[] } : null
      if (!response.ok || !result) {
        setNotice(saveNotice(false, result?.errors?.join(' ') || 'Could not read that file.', 'Not imported'))
        return
      }
      setSource({ kind: 'json', json, status: result })
    } catch {
      setNotice(saveNotice(false, SAVING_OFF, 'Not imported'))
    }
  }

  return (
    <div className="be-scrim" onClick={busy ? undefined : onClose}>
      <aside className="be-drawer be-hire sync-drawer" role="dialog" aria-labelledby="sync-title" onClick={(event) => event.stopPropagation()}>
        <div className="be-hire-scroll">
          <header className="be-hire-head">
            <h2 id="sync-title">Sync with Grok Bot</h2>
            <button type="button" className="be-icon" onClick={onClose} aria-label="Close" disabled={busy}>
              ×
            </button>
          </header>
          <p className="overview-note">{shown ? statusLine(shown, orgSlug) : 'Checking for a snapshot…'}</p>
          <p className="overview-note">
            <a href={`#/org/${orgSlug}/overview`}>Set up the Connector on Organization Overview</a>
          </p>
          {source.kind === 'json' ? (
            <p className="overview-note">Previewing an imported file. <Button variant="secondary" type="button" onClick={() => setSource({ kind: 'file' })}>Back to the snapshot</Button></p>
          ) : null}
          {plan ? <Preview plan={plan} /> : null}
          {notice ? <SaveAlert kind={notice.kind}>{notice.message}</SaveAlert> : null}
          <details className="link-panel">
            <summary>
              <span>No snapshot? Ask Grok Bot for one</span>
              <span className="grok-chevron" aria-hidden="true" />
            </summary>
            <div className="link-panel-body">
```
